# Lição 6.2 — Custom visualizations

> Módulo 6 · Visualizing observability data · Lição 6.2
> Espelha a lição **6.2** do curso oficial *Elastic Observability Engineer*.

## Objetivo

Escolher e construir a visualização certa para cada pergunta. Lens como editor padrão, Maps para dado geográfico, e o critério que evita o gráfico bonito e ilegível.

## Tópicos

- Lens: o editor padrão, orientado a arrastar e soltar
- O catálogo: métrica, linha/área, barras, tabela, heat map, treemap, pizza
- Maps: visualizar dado com informação geográfica
- A pergunta define o gráfico (não o contrário)
- Cardinalidade nos eixos: quando o Top N deixa de ser preguiça e vira engenharia
- Reorganizar painéis no modo de edição
