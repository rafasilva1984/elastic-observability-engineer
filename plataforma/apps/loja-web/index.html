Loja ONP

Aplicação de demonstração do curso Observabilidade na Prática (preparação para o exame Elastic Certified Observability Engineer).

Ela existe para ser observada: é alvo de uptime, gera logs, métricas e traces.

  • API da loja: http://localhost:5000
  • Endpoint saudável: /api/pedidos
  • Endpoint lento: /api/lento
  • Endpoint com erro: /api/erro
